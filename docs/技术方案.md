# macOS 原生首版

AppKit 管理菜单栏、全局快捷键和 NSPanel。浮页正文使用 WKWebView，复用已验证的行间注交互。正式阅读页和管理台的 HTML、样式、交互脚本均位于 `macOS/`，构建时直接打包。导入原文走用户主动选择的菜单动作，探索索引当前使用 UserDefaults。问题、来源区间、草稿及阅读位置由本机 WebKit 存储保存，按探索 ID 分开。首版未做大文档迁移、导出或数据库容量保障。

Swift 将问题交给随包的 Python 3 适配器。适配器通过标准输入输出连接本机 Codex App Server，使用现有登录态。每次发送建立临时线程，确认 ephemeral 为真才提交文本。输入包括完整导入原文、当前问题的祖先路径及当前分支对话。代价是长会话会重复消耗上下文，后续应增加长度预算和摘要。子分支内容不进入父问题的对话路径。启动线程前读取当前 CLI 的有效配置，并仅对已配置的 MCP 服务设置禁用覆盖。使用独立临时工作目录、只读沙箱和无审批模式，拒绝服务端发起的工具请求；初版一次处理一个回答。

逐段文本更新对应问题节点；完成后本地渲染 Markdown 与 KaTeX。网页按允许列表重建格式元素，忽略模型给出的 HTML 属性，网页导航限制到本地阅读资源。连接失败显示错误并保留用户问题。初版依赖 macOS 上可用的 /usr/bin/python3 和开发者工具。发布前应打包固定运行时或把协议适配器移入 Swift。

验证层次：临时线程协议握手、文本增量与结束事件；实际签名 app 中的 WebKit → Swift → App Server → WebKit；人工测试真实键盘、Space 切换、点外收起及 ChatGPT 侧栏前后对照。协议层验证不能替代官方客户端侧栏的人工检查。
