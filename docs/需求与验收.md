# SideAsk 需求基线

目标是在读完整篇长回答时补足跳过的推导或概念，弄懂后回到原句。用户主动导入的每篇回答对应一次探索，原文和其中的全部一阶问题保存在 SideAsk。导入后默认进入提问，全文只在主动查看背景时展开；日常阅读继续在来源应用进行。旁支结论不回写原回答，官方 ChatGPT 历史应零新增。

| 使用动作 | 约定行为 |
| --- | --- |
| 呼出和收起 | 全局快捷键切换，浮页默认靠右，允许跨过屏幕中线、移动、拉宽。点击外部收起，保留草稿、阅读位置。菜单栏或 Dock 的常规窗口用于管理。 |
| 引用或自由问 | 引用与问题输入各占一行，引用可空。新复制原文片段准备新的一阶问题，无新片段恢复上次停留处。待发送的草稿与已创建的问题分别保存。 |
| 连续追问 | 直接发送就在当前问题里续聊。「＋ 新问题」直接准备本篇的一级问题。选句后点「单独问」才准备子问题，发送才创建标注。最多三级，第三级仍能连续对话。 |
| 阅读行间注 | 一级问题与来源引用同在页首。正文宋体，统一字号行高。引用词着色，段末用小书签标记旁注，问题标题可在下拉目录中浏览。点击注标后打开独立的左侧悬浮卡，右侧原回答保留原来的窗口、正文、滚动位置和输入草稿。左卡与主卡并排等高，随主卡移动和调整大小，正文独立滚动。旁注页首先显示问题标题，其次是引用，页缘标出Ⅱ或Ⅲ。单击一级卡片的阅读留白收起旁注；点击文字、公式、输入区和工具按钮时保留旁注。三级卡从下向上出现，露出二级问题的可点击后缘，返回时恢复上一层的阅读位置和草稿。两张卡各自有圆角和系统投影，空间不足时允许错叠。 |
| 找回疑问 | 本篇目录按原文位置列一级问题，子问题按创建顺序，未定位的问题单列。打开某项恢复上次位置和草稿。 |
| 内容质量 | 实时显示回复，支持 Markdown、公式和代码。引用里的公式排版显示，点击引用可编辑原文。首版不假设教学示意图自动生成。 |

开发验收优先级：真实登录态下的临时线程和流式回答 → 原文、对话及草稿重启恢复 → 用真实长文核对三级返回、焦点、中文输入法及剪贴板切换 → 常规管理窗口与多屏体验。行间注标负责入口，展开态试用双卡阅读。

## 在本机复查

从项目根目录运行 `./scripts/build.sh` 后，可使用应用内置的验收入口。导入和旁注检查使用临时对话数据；Codex 检查会提交一条真实测试提问并使用当前账户的模型额度。

```sh
./build/SideAsk.app/Contents/MacOS/SideAsk --verify-import
./build/SideAsk.app/Contents/MacOS/SideAsk --verify-pair
./build/SideAsk.app/Contents/MacOS/SideAsk --verify-codex
```

## macOS 干净安装验收记录 · 2026-11-09

验收环境为 Apple Silicon、macOS 27.2、Swift 6.4.2、系统 Python 3.9.6 和独立 Codex CLI 0.162.1。应用从仅含正式源码与构建脚本的临时目录构建，复制到空的安装目录并通过本地签名完整性校验。普通启动使用单独的测试应用标识，验证 macOS 能打开管理台；对话验收使用临时 WebKit 存储。

| 场景 | 实测结果 |
|---|---|
| 无个人 Codex 配置，仅复用既有登录 | 浮页发出测试提问，收到并显示 `SIDEASK_OK` |
| 导入与阅读 | 长文和附件创建探索、旁注切换、草稿恢复、归档与恢复、快捷键及三级浮页检查通过 |
| 提取与追问 | 合成 PDF、DOCX、PPTX 分别定位到页、段落和幻灯片。真实回复准确返回 PDF 中的测试口令，引用地址对应原文件第一页 |
| 已配置外部 MCP 服务 | 验收服务未被启动，资料追问正常完成 |

范围为本机从源码构建和安装。其他 macOS 版本、Intel Mac、互联网下载后的 Gatekeeper 公证分发，以及官方 ChatGPT 侧栏的人工前后对照均未在这次验收中验证。
